# 操作手册

## 1. 启动与登录

```powershell
cd "F:\MidPnP Studio"
.\run.ps1
```

首次启动会：

1. 创建本地数据目录 `%LOCALAPPDATA%\MidPnP Studio`；
2. 初始化 SQLite 数据库；
3. 写入 35 点演示产品、7 种元件、7 台供料器和 2 条演示生产记录；
4. 根据设置自动连接内置模拟器（默认开启）。

界面左下角显示当前模式；顶栏右侧显示连接状态、时钟、操作员和红色急停按钮。

## 2. 生产总览

- **KPI 卡片**：今日产出、直通率、平均节拍（CPH）、今日批次。
- **设备状态**：当前状态、轴坐标、当前产品、预计节拍、供料器就绪率。
- **开始生产**：切换到生产执行页；未连接时先发起连接。
- **最近生产 / 设备动态**：生产记录与最新日志。
- **快捷操作**：产品编程、供料器、手动控制、视觉对位。

## 3. 生产执行

1. 顶栏产品下拉框选择产品。
2. 检查右侧「生产控制」：状态应为 **就绪**，进度环为 0%。
3. 点击 **开始生产**。若存在缺料、缺元件、超行程等问题，会弹出「生产前检查」对话框，按提示修复后再开始。
4. 生产过程中：
   - 机台视图显示贴装头实时位置；
   - 进度环显示百分比与完成点数；
   - 贴装队列表格自动滚动到当前位号，状态依次变为「贴装中 → 完成」；
   - 右侧显示当前位号、供料器、已用时、预计剩余。
5. 可随时 **暂停 / 继续**；**停止** 会结束本批次并保留已完成记录。
6. 完成后自动写入生产记录，扣减供料器余料，并显示完成提示。

### 报警与急停

- 红色 **急停** 按钮：立即中止运动、关闭真空、进入 `ESTOP`。
- 报警横幅出现后，排除风险，点击 **复位报警**。
- 急停复位前无法开始新的生产。
- 软件急停不替代硬件安全回路。

## 4. 产品编程

- **新建 / 复制 / 删除**：管理产品。
- **产品参数**：名称、版本、板宽/板高/板厚、板原点、备注。
- **板卡布局**：单击贴装点选中；滚轮缩放、拖拽平移、双击复位；选中点会显示位号与元件名。
- **贴装点**：添加、编辑、删除；双击表格行也可以编辑。
- **保存产品**：有未保存修改时右上角显示「有未保存修改」，切换产品前会提示保存。

### 坐标约定

- 坐标单位 mm；
- 板内坐标以板框左下角为原点，X 向右、Y 向上；
- 板原点 `(origin_x, origin_y)` 是板框左下角在机器台面上的位置；
- 旋转角逆时针为正。

### CSV 导入

支持 `文件 → 导入 CSV`，自动识别逗号/分号/Tab，兼容中英文表头。

最小字段：

| 字段 | 常见表头 |
| --- | --- |
| 位号 | `Designator` / `RefDes` / `Ref` / `位号` |
| X | `Mid X (mm)` / `X` / `PosX` / `坐标X` |
| Y | `Mid Y (mm)` / `Y` / `PosY` / `坐标Y` |

可选字段：`Comment / Value / 元件`、`Footprint / Package / 封装`、`Rotation / 角度`、`Layer / Side / 面`、`Skip / DNP / 不贴`、`Unit`。

示例：

```csv
Designator,Comment,Footprint,Mid X (mm),Mid Y (mm),Rotation,Layer
R1,10k,0603,12.5,22.0,90,Top
C1,100nF,0603,14.0,22.0,0,Top
U1,MCU,QFN-24,50.0,55.0,0,Top
```

导入时：

- 缺失元件会自动创建（通用尺寸与吸嘴策略），导入后请到元件库确认封装尺寸。
- 已有产品可选择「替换现有」或「追加合并」。
- 追加时同位号会覆盖旧点。
- 导入结束后需要点击 **保存产品** 才会写入数据库。

### CSV 导出

导出当前编辑内容，编码为 UTF-8 with BOM，Excel 可直接打开。

## 5. 供料器

- 每个料站包含：槽位、元件、容量、余料、料带间距、取料坐标、低料阈值、启用状态。
- 进度条颜色：绿色正常、橙色低料、红色空料。
- **补满余料**：直接设置为容量；也可输入任意补料后数量。
- **停用**：生产前检查会跳过该供料器，若元件没有其他可用料站则报错。
- 修改取料坐标后需确认与真实料站位置一致，再手动低速验证。

低料阈值默认 15%。在系统设置中开启「供料器低料时停止生产」后，低料会直接阻止开始生产。

## 6. 元件库

- 维护名称、封装、长宽高、吸嘴、视觉策略、速度、预览颜色、备注。
- 删除前会检查引用：被供料器或产品贴装点引用的元件不能删除。
- 右侧预览显示封装比例与尺寸。
- 元件尺寸会影响板卡画布中的封装绘制，但不参与碰撞检查（v0.1 未实现）。

## 7. 手动控制

- **点动**：X/Y 方向键、Z+/Z-，步长 0.1 / 1 / 10 mm，速度 5–100%。
- **快捷定位**：安全高度、板卡中心、机械原点、料站 01。
- **真空**：打开/关闭；状态同步到顶栏与页内 IO 状态。
- **吸嘴**：N1–N4 切换。
- **传送带**：进板 / 停止 / 退板。
- **照明**：开 / 关。
- **供料器点动**：指定槽位前进一个料位，会扣减余料。
- 生产运行中手动轴控被锁定。

> 真机首次调试必须空载、低速、单步，确认方向与限位后再提速。

## 8. 视觉对位（仿真）

当前视觉页是离线仿真：

- 相机画面、扫描线、Mark 点、偏差与置信度均为程序生成；
- **采集图像**：模拟采集一帧；
- **执行对位**：模拟搜索当前产品的第一个基准点，输出 dX / dY / dTheta / 置信度；
- **示教基准点**：将当前产品第一个 Mark 点记录到日志；
- 顶部明确标注「离线仿真」。

接入真实相机时，需要替换 `VisionView` 的图像源，并把对位结果接入贴装坐标补偿。v0.1 不会把视觉偏差自动写入生产计划。

## 9. 系统日志

- 级别筛选：全部 / INFO / WARN / ERROR / DEBUG；
- 内容/来源搜索；
- 4 秒自动刷新；
- 选中行查看完整消息；
- 导出 CSV、清空日志（不可撤销）。

日志同时保存在 SQLite 的 `logs` 表，最多保留约 5000 条。

## 10. 系统设置

- **设备与连接**：机器名称、操作员、模拟器/TCP/串口、IP/端口、串口/波特率、仿真速度。
- **生产选项**：路径优化、开始前二次确认、低料停止、视觉来源、日志级别。
- **机器行程**：X/Y/Z 行程、安全高度、最大速度、吸嘴数量。
- **数据与维护**：打开数据目录、备份数据库、重置演示数据。
- 修改连接或行程后需要 **重新连接** 才生效；生产运行中不要修改。

## 11. 常见问题

**Q：启动后一直显示离线？**
检查「系统设置」中的连接方式。模拟器模式应显示 `模拟器 · MidPnP M1`；TCP 模式确认控制器 IP/端口与防火墙；串口模式确认 COM 口未被其他软件占用。

**Q：开始生产提示「没有可用供料器」？**
到供料器页检查该元件的料站是否启用、余料是否大于 0，或新增一个料站。

**Q：CSV 导入后坐标不对？**
确认 CSV 的 X/Y 是板内坐标，单位 mm；如果是 mil，请使用 `Mid X (mil)` 表头或在 `Unit` 列写 `mil`。检查板原点设置。

**Q：如何完全恢复演示数据？**
系统设置 → 重置演示数据。会删除全部产品/元件/供料器/生产记录。

**Q：数据在哪？如何迁移？**
默认 `%LOCALAPPDATA%\MidPnP Studio`。关闭软件后复制整个目录即可迁移；也可在设置页备份 `.db` 文件。

**Q：能否直接控制真实贴片机？**
需要按控制器协议实现 `MachineBackend`，并用 `tools/machine_sim_server.py` 先做协议联调。真实硬件安全回路必须独立。

## 12. 退出

- 若生产运行中退出，会提示确认并先停止任务。
- 设置自动保存；生产记录和日志实时落库。
- 直接关闭窗口即可，机器连接会断开。
